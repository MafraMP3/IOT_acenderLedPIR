## Enunciado: Vamos ligar o LED!

O projeto vai utilizar um sensor PIR como entrada para controlar um LED como saída. Ao acionar o sensor, o Arduino altera o estado do LED.

- O Arduino lê o estado do sensor pelo **pino 7**
- Controla o LED pelo **pino 6**
